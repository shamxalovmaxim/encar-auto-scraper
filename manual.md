## 1. Назначение и возможности комплекса

Программный комплекс предназначен для сбора информации об автомобилях с южнокорейской площадки **Encar.com** в режиме реального времени.

### Основные возможности:

* **Автономный сбор данных**: сбор актуальных параметров автомобилей (марка, модель, комплектация, год, пробег, цена, топливо, КПП, ссылки на фото и интерактивную карточку).

* **Защита от дублей (Smart Upsert)**: система автоматически обновляет цены и пробег у ранее добавленных машин, не создавая копий.

* **Локальная русификация**: автоматический перевод корейских названий, серий, моторов и комплектаций на русский и международный английский язык без сетевых задержек.

* **Гибкий экспорт**: формирование отчетов в формате Excel (с готовыми автофильтрами, разделителями чисел и нативными гиперссылками) и CSV (кодировка UTF-8 BOM, открывается без сбоев в Excel и CRM).

* **Ротация сетевых подключений**: поддержка пула прокси с циклическим переключением и безопасным прямым подключением.

* **Встроенный планировщик**: сбор данных каждые $N$ минут без участия человека.

## 2. Первоначальная настройка и запуск с нуля

Для запуска сервиса необходимы три параметра: **токен бота**, **ваш цифровой Telegram ID** и **интервал автоматического сбора**.

### 2.1. Создание бота и получение токена

1. Откройте мессенджер Telegram и найдите официального бота: [**@BotFather**](https://t.me/BotFather).

2. Отправьте команду `/newbot`.

3. Введите отображаемое имя для вашего бота (например, `Encar Manager Bot`).

4. Введите юзернейм бота на латинице, обязательно оканчивающийся на `bot` (например, `my_encar_cars_bot`).

5. **@BotFather** пришлет сообщение с токеном доступа (API Token). Скопируйте его. Токен имеет вид:

   ```
   7123456789:AAFlkjw09e8fjaslkf0111jkdsfаkjsdf
   
   
   ```

### 2.2. Получение вашего Telegram ID

Бот защищен встроенной системой прав: управлять им может только владелец.

1. Найдите в Telegram бота [**@userinfobot**](https://t.me/userinfobot).

2. Нажмите **Start**. Бот пришлет строку с вашим числовым `Id` (например, `594837261`).

### 2.3. Заполнение конфигурационного файла `.env`

В корневой папке проекта создайте (или откройте существующий) текстовый файл **`.env`** и внесите полученные данные:

```
# Токен доступа Telegram Bot API
BOT_TOKEN=7123456789:AAFlkjw09e8fjaslkf0111jkdsfаkjsdf

# Ваш цифровой Telegram ID
ADMIN_ID=594837261

# Интервал автоматического сбора объявлений в минутах (0 - отключить автосбор)
SCHEDULE_INTERVAL_MINUTES=60


```

> ⚠️ **Безопасность:** Никогда не передавайте файл `.env` и токен бота третьим лицам. Доступ к токену позволяет управлять ботом от вашего имени.

## 3. Настройка и ротация прокси-серверов

Парсер оснащен отказоустойчивым менеджером соединений. Он может работать как через выделенные прокси (для обхода ограничений частоты запросов), так и напрямую через сетевой интерфейс сервера.

### Формат файла `proxies.txt`

Для подключения прокси создайте в корневой директории файл **`proxies.txt`** и укажите адреса построчно:

```
http://proxy_user:proxy_password@185.220.101.5:8080
http://proxy_user:proxy_password@185.220.101.6:8080
http://92.118.45.12:3128


```

### Принцип работы ротации:

1. **Циклическое переключение**: Запрос первой страницы Encar идет через Прокси №1, второй — через Прокси №2, и так далее по кругу (`itertools.cycle`).

2. **Прямой режим (Fallback)**: Если файл `proxies.txt` пуст или не существует, система выводит информационную запись в лог и автоматически собирает данные через основной IP-адрес сервера без ошибок.

### 4.2. Ручной запуск и мягкая остановка сбора

* **Кнопка `▶️ Запустить парсер`**: запускает сбор данных в фоновом режиме через асинхронную задачу (`asyncio.create_task`). Чат не блокируется — вы можете проверять статус или заказывать выгрузки прямо во время работы парсера.

* **Кнопка `⏹ Остановить`**: посылает флаг мягкой остановки (`stop_requested = True`). Парсер не обрывает связь аварийно, а корректно сохраняет уже загруженную пачку машин в базу и безопасно завершает процесс.

### 4.3. Диагностика и мониторинг состояния базы

Нажатие на кнопку **`📊 Статус системы`** возвращает актуальный снимок состояния сервиса:

### 4.4. Выгрузка в Excel (.xlsx) и особенности отчета

При нажатии на **`📁 Экспорт в Excel`** бот генерирует коммерческий отчет со следующими параметрами:

1. **Темно-синяя шапка с автофильтрами**: на всех столбцах активны стрелочки фильтрации и сортировки (по цене, году, пробегу).

2. **Закрепленная верхняя строка**: при прокрутке таблицы вниз заголовки колонок всегда остаются на виду.

3. **Числовые форматы**: пробег и цена отформатированы с разделением тысяч (`162 743` вместо `162743`).

4. **Кликабельные гиперссылки**:

   * **Колонка «Объявление на Encar»** $\rightarrow$ ссылка **`🔗 Открыть на Encar (Галерея)`**. Открывает интерактивную страницу машины на Encar с полным слайдером всех фотографий, осмотром салона 360° и отчетом о страховых выплатах.

   * **Колонка «Главное фото (CDN)»** $\rightarrow$ ссылка **`🖼 Главное фото`**. Мгновенно открывает прямую качественную фотографию автомобиля.

### 4.5. Выгрузка в CSV (.csv) для CRM и внешних баз

Кнопка **`📄 Экспорт в CSV`** формирует структурированный файл с разделителем точка с запятой (`;`) и кодировкой **UTF-8 с сигнатурой (BOM)**:

* Корректно открывается двойным кликом в русском Excel без сбивки колонок и превращения кириллицы в иероглифы.

* Готов для импорта в любую базу данных (PostgreSQL, MySQL), Google Таблицы или CRM-системы (Битрикс24, amoCRM).

### 4.6. Создание и скачивание резервной копии базы данных

Кнопка **`💾 Скачать дамп БД`** отправляет вам в чат оригинальный файл **`encar_cars.db`**.

* Используется для создания локальных бекапов перед обновлением сервера или для переноса базы на другой компьютер.

* Файл можно открыть в бесплатной программе **DB Browser for SQLite** для составления прямых SQL-запросов любой сложности.

## 5. Автоматический фоновый сбор по расписанию

Сервис снабжен планировщиком задач **APScheduler**, работающим в общем цикле событий `asyncio`.

* Период задается в параметре `SCHEDULE_INTERVAL_MINUTES` файла `.env`.

* При значении `60` бот автоматически каждый час обращается к каталогу Encar, выгружает свежие поступления и обновляет базу.

* Если в момент срабатывания таймера парсер уже запущен администратором вручную, планировщик безопасно пропустит итерацию, предотвратив конфликт одновременной записи.

## 6. Архитектура данных: Smart Upsert и сброс базы

### Принцип работы Smart Upsert (Умное обновление)

В отличие от простых парсеров, создающих сотни дубликатов, система сверяет уникальный идентификатор машины (`ID Encar`):

* **Новый автомобиль** $\rightarrow$ добавляется новой строкой в базу.

* **Автомобиль уже в базе** $\rightarrow$ скрипт обновляет актуальную цену (если корейский дилер изменил стоимость), пробег и ставит дату обновления в поле `updated_at`.

### Как выполнить полный сброс базы данных (Reset)

Если вам необходимо удалить все накопленные данные и начать мониторинг с чистого листа:

1. Остановите бота в консоли комбинацией клавиш **`Ctrl + C`**.

2. Удалите файл **`encar_cars.db`** из папки проекта.

3. Запустите бота снова (`python bot.py`).

4. При старте бот автоматически сгенерирует новую чистую структуру базы данных.

## 7. Решение нештатных ситуаций (Troubleshooting & FAQ)

### Бот не реагирует на нажатия кнопок или команду `/start`

* **Причина 1**: Не совпадает ваш Telegram ID. Проверьте правильность значения `ADMIN_ID` в файле `.env`.

* **Причина 2**: Процесс бота остановлен в терминале или на сервере. Проверьте, запущена ли служба.

### Ошибка `База данных заблокирована (sqlite3.OperationalError: database is locked)`

* **Причина**: Файл `encar_cars.db` открыт в сторонней программе (например, DB Browser for SQLite) в режиме редактирования с монопольной блокировкой.

* **Решение**: Закройте сторонние утилиты просмотра баз данных.

### Ошибка `ConnectTimeout` или долгий сбор страниц

* **Причина**: Один или несколько прокси-серверов из файла `proxies.txt` перестали отвечать или заблокированы со стороны корейского провай
