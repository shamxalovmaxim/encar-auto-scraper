# 🚗 Encar Auto Scraper & Telegram Bot

Асинхронный сервис мониторинга и парсинга южнокорейского автоаукциона **Encar.com** с панелью управления в Telegram, локальной базой данных SQLite и экспортом аналитических отчётов в Excel и CSV.

---

## 🛠 Стек технологий

* **Язык:** Python 3.10+
* **Фреймворк бота:** `aiogram 3` (асинхронная архитектура)
* **Сетевой слой:** `httpx` (пулы HTTP/2 соединений, ротация заголовков и мобильных User-Agent)
* **База данных:** SQLite через `aiosqlite` (схема Upsert без дубликатов)
* **Генерация отчётов:** `pandas`, `openpyxl` (нативная стилизация, финансовые форматы, CDN-ссылки)
* **Фоновые задачи:** `APScheduler`
* **Окружение:** `python-dotenv`

---

## ⚡ Ключевые возможности

* **Высокоскоростной парсинг:** прямой сбор данных через скрытые мобильные API Encar без использования тяжёлых браузерных эмуляторов (Selenium/Playwright).
* **Умная нормализация:** локальный лексический токенизатор и Regex для мгновенного перевода корейских марок, моделей, типов топлива и комплектаций на русский/английский языки.
* **Интерактивные отчёты:**
* **Excel (.xlsx):** кликабельные ссылки на галереи авто и панорамы 360°, финансовый формат чисел, закреплённая шапка и автоширина столбцов.
* **CSV (.csv):** совместимость с русскоязычным Excel (`utf-8-sig`, разделитель `;`).


* **Telegram-интерфейс:**
* Запуск и остановка парсинга по кнопке;
* Мгновенная выгрузка базы данных в чат;
* Настройка интервалов автосканирования;
* Безопасная изоляция доступа по `ADMIN_ID`.



---

## 📂 Структура проекта

* `bot.py` — запуск Telegram-бота, хэндлеры команд и инлайн-клавиатуры.
* `parser.py` — модуль асинхронного сбора данных с Encar.
* `database.py` — асинхронная работа с SQLite (идемпотентная запись `ON CONFLICT DO UPDATE`).
* `exporter.py` — движок форматирования отчётов Excel и CSV.
* `config.py` — конфигурация путей и переменных окружения.
* `manual.md` — полное руководство администратора по установке и запуску.
* `ARCHITECTURE.md` — описание системной архитектуры и потоков данных.

## 🚀 Быстрый запуск

1. Клонировать репозиторий:
```bash
git clone https://github.com/shamxalovmaxim/encar-auto-scraper.git
cd encar-auto-scraper

```


2. Создать и активировать виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или venv\Scripts\activate для Windows

```


3. Установить зависимости:
```bash
pip install -r requirements.txt

```


4. Создать файл `.env` на основе примера:
```env
BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_id

```


5. Запустить сервис:
```bash
python bot.py

```



Подробные инструкции по установке на сервер и настройке автозапуска через `systemd` находятся в [manual.md](manual.md).
