## 1. Концепция и назначение сервиса

Сервис спроектирован как автономный серверный демон для решения бизнес-задач импорта автомобилей:
1. Непрерывный мониторинг свежих предложений на корейском рынке без необходимости работы с веб-интерфейсом Encar.
2. Исключение человеческого фактора при расчёте характеристик за счёт автоматической локализации корейских терминов.
3. Предоставление бизнес-пользователю готовых аналитических отчётов в Excel (.xlsx) и CSV (.csv) по клику в Telegram.
4. Надежное долговременное хранение истории рынка с защитой от дублирования объявлений.

## 5. Анализ и реверс-инжиниринг API Encar.com

Вместо парсинга сырого HTML через браузерные эмуляторы (Selenium/Playwright), требующие гигабайты памяти, сервис работает напрямую с внутренним мобильным/веб API платформы Encar.

### 5.1. Эндпоинт поиска

* **URL**: `https://api.encar.com/search/car/list/general`
* **Метод**: `GET`
* **Формат ответа**: `application/json`

### 5.2. Параметры запроса

```text
count=true
q=(And.Hidden.N._.CarType.A.)
sr=|ModifiedDate|{start_index}|{page_size}

```

* `count=true`: получение метаданных об общем количестве доступных лотов.
* `q=(And.Hidden.N._.CarType.A.)`: базовый фильтр активных, не скрытых объявлений о продаже легкового транспорта.
* `sr=|ModifiedDate|{offset}|{limit}`: пагинация со строгой сортировкой по дате обновления/добавления (`ModifiedDate`).

### 5.3. Механизм адресации медиафайлов

Сервер API не отдаёт полные URL-адреса фотографий, а возвращает массив путей расположения (`location`).
Скрипт транслирует относительный путь во внешний публичный CDN:
`https://ci.encar.com{location}`

Прямой переход на интерактивную веб-страницу формируется по уникальному идентификатору авто:
`https://www.encar.com/dc/dc_cardetailview.do?carid={Id}`

## 6. Схема базы данных и механизм Smart Upsert

База данных состоит из единой денормализованной таблицы `cars`, оптимизированной под быструю запись и пакетную выборку.

### 6.1. DDL-структура таблицы

```sql
CREATE TABLE IF NOT EXISTS cars (
    id TEXT PRIMARY KEY,
    manufacturer TEXT,
    model TEXT,
    badge TEXT,
    badge_detail TEXT,
    year INTEGER,
    form_year INTEGER,
    mileage INTEGER,
    price INTEGER,
    fuel_type TEXT,
    transmission TEXT,
    photos_json TEXT,
    created_at TEXT,
    updated_at TEXT
);

CREATE INDEX IF NOT EXISTS idx_cars_created_at ON cars(created_at);

```

### 6.2. Идемпотентность и Smart Upsert

Для исключения дубликатов при регулярных запусках парсера используется нативная конструкция стандарта SQLite 3.24+:

```sql
INSERT INTO cars (
    id, manufacturer, model, badge, badge_detail,
    year, form_year, mileage, price, fuel_type,
    transmission, photos_json, created_at, updated_at
) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
ON CONFLICT(id) DO UPDATE SET
    manufacturer = excluded.manufacturer,
    model = excluded.model,
    badge = excluded.badge,
    badge_detail = excluded.badge_detail,
    year = excluded.year,
    form_year = excluded.form_year,
    mileage = excluded.mileage,
    price = excluded.price,
    fuel_type = excluded.fuel_type,
    transmission = excluded.transmission,
    photos_json = excluded.photos_json,
    updated_at = excluded.updated_at;

```

* **Сохранение первоначальной даты**: колонка `created_at` фиксирует дату первого обнаружения лота и не перезаписывается.
* **Динамическое обновление**: метрики `price`, `mileage` и дата `updated_at` обновляются на лету, что позволяет фиксировать снижение цены дилером.

## 7. Сетевая архитектура и обход защит (Anti-Blocking)

### 7.1. Конкурентный пул с ограничением нагрузки

Обращения к API Encar регулируются через `asyncio.Semaphore(5)`. Это предотвращает лавинообразные сетевые всплески, защищая процесс от банов по сигнатуре DDOS-атаки, сохраняя при этом преимущества асинхронного ввода-вывода.

### 7.2. Ротация прокси (Proxy Rotation & Failover)

Модуль `parser.py` инициализирует бесконечный кольцевой буфер адресов через `itertools.cycle`:

```python
self.proxy_pool = itertools.cycle(self.raw_proxies) if self.raw_proxies else None

```

* Каждый сетевой запрос из пула задач берет следующий прокси по кругу.
* При отсутствии адресов в `proxies.txt` транспорт переключается на прямой сетевой стек операционной системы без падения приложения.
* Сетевые ошибки (ConnectTimeout, ProxyError) отлавливаются на уровне единичного запроса, сохраняются в телеметрию стейта `last_error` и не приводят к аварийной остановке всего цикла.

## 8. Движок нормализации и локализации данных

Сервис не использует внешние веб-переводчики (Google Translate API) при выгрузке отчетов во избежание сетевых задержек (Latency) и исчерпания лимитов (HTTP 429 Too Many Requests).

Нормализация выполняется оффлайн-движком `clean_korean()`:

1. **Регулярные выражения (Regex)**:
* `(\d+)\s*세대` $\rightarrow$ `{N} поколение`
* `(\d+)\s*인승` $\rightarrow$ `{N} мест`


2. **Лексический токенизатор**:
* Применяется сортировка терминов словаря по убыванию длины строки (`key=len, reverse=True`). Это исключает ошибки частичного замещения сложных составных терминов (например, замена «더 뉴 카니발» целиком, а не отдельного слова «카니발»).
* Обработка 1000 строк занимает менее 0.05 секунды.

## 9. Формирование аналитических отчетов

### 9.1. Excel (.xlsx) с нативной разметкой OpenXML

В отличие от стандартной выгрузки библиотекой `pandas`, модуль `exporter.py` осуществляет низкоуровневую постобработку рабочей книги `openpyxl`:

* **Нативные ссылки**: вместо нестабильных локализованных формул `=HYPERLINK()` адреса привязываются к объектной модели клетки `cell.hyperlink = url`, что гарантирует корректное открытие галереи в любом браузере и ОС.
* **Числовой формат**: для столбцов пробега и цены применяется финансовый маппинг `#,##0`, разделяющий тысячи пробелами.
* **Юзабилити**: закреплена верхняя строка заголовков (`freeze_panes = "A2"`), включены автоматические фильтры диапазона данных, выполнен автоподбор ширины колонок по длине контента.

### 9.2. CSV (.csv) для CRM и внешних баз

* Кодировка: **`utf-8-sig`** (UTF-8 с сигнатурой BOM). Это заставляет Microsoft Excel корректно определять кириллицу при двойном клике без кракозябр.
* Разделитель: **`;`** (точка с запятой), что соответствует стандарту табличных редакторов для европейской и российской локали.
